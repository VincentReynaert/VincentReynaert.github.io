Application requise

Installez URPS Obésité pour continuer

Cette application est réservée à une utilisation depuis l’écran d’accueil de votre iPhone ou iPad.

  1. Dans Safari, touchez Partager (le carré avec une flèche vers le haut).
  2. Choisissez Sur l’écran d’accueil.
  3. Touchez Ajouter, puis ouvrez URPS Obésité depuis l’icône créée.

Installez l’application pour accéder au parcours.

Utilisez le menu de votre navigateur, puis choisissez « Installer l’application ».

L’accès dans le navigateur est volontairement désactivé.
