Installation sur iPhone ou iPad

Ajouter URPS Obésité à l’écran d’accueil

  1. Dans Safari, touchez Partager (carré avec une flèche vers le haut).
  2. Choisissez Sur l’écran d’accueil.
  3. Validez avec Ajouter, puis ouvrez l’outil depuis son icône.

L’installation est facultative : le site reste utilisable directement dans Safari.
